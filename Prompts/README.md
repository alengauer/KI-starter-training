# Prompt-Dateien zu den Teilnehmerunterlagen

Jede Datei enthält einen Prompt einer Übung vollständig: mit den benötigten Anforderungstexten aus Anhang A und, wo ein Prompt auf ein früheres Ergebnis aufbaut, mit einem Beispielergebnis. Jede Übung lässt sich damit auch ohne den vorherigen Schritt bearbeiten.

## Verwendung

1. Die in der Übung genannte Datei öffnen (Texteditor oder Markdown-Ansicht).
2. Den Inhalt des grau hinterlegten Kastens vollständig kopieren. Im Texteditor stehen über und unter dem Kasten die Begrenzungszeilen `` ```text `` und `` ``` ``; sie werden nicht mitkopiert.
3. In den Chat einfügen und absenden. Die Zeilen über dem Kasten nennen, in welchem Chat der Prompt gesendet wird und welche Stelle bei Bedarf durch ein eigenes Ergebnis ersetzt werden kann.

Markierungen wie `<anforderung>` und `</anforderung>` grenzen das Material von der Anweisung ab und bleiben stehen. Weitere Angaben in spitzen Klammern sind Formatvorgaben für das Modell und bleiben ebenfalls stehen; Ausnahme ist das Gerüst der SKILL.md in Übung 1b, das selbst ausgefüllt wird.
